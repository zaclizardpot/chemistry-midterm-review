CHAPTER 01

一、有效位數判斷

有效位數（significant figures）表示一個測量值中具有意義的數字；判斷時要分清楚哪些 0 是測量資訊，哪些只是用來標示小數點位置。

算有效位數的數字

  1. 所有非 0 的數字。
  2. 夾在非 0 數字之間的 0 。
  3. 有小數點時，結尾 0 。

不算有效位數的 0

  1. 第一個非 0 數字前面的 0 。
  2. 沒有小數點時，整數結尾 0 。
數值有效位數判斷原因
16.074夾在非 0 數字之間的 0 有效。
13.004有小數點，結尾的兩個 0 有效。
0.00122前面的 0 只用來定位小數點。
0.31小數點後、第一個非 0 前的 0 無效。
150通常為 2沒有小數點，末尾 0 通常不視為有效。
整數末尾 0 可能有歧義：300 無法清楚表示想保留幾位有效數字。要表達 1、2、3 位有效數字時，最好分別寫成 3 × 102、3.0 × 102、3.00 × 102。

二、有效位數運算

不是所有運算都使用同一種判斷方式：乘除看「有效位數」，加減看「小數位數」。

乘法與除法

答案的有效位數，等於題目中有效位數最少的數值。

例如：

2.5 × 3.42 = 8.55
2.5 只有 2 位有效數字，因此答案寫成 8.6（2 位有效數字）。

加法與減法

答案保留的小數位數，等於題目中小數位數最少的數值。

例如：

12.11 + 0.3 = 12.41
0.3 只精確到小數第 1 位，因此答案寫成 12.4。
運算判斷標準要找最少的什麼？
乘法、除法有效位數最少有效位數
加法、減法小數位置最少小數位數／最不精確位
不要混在一起：「least digit」若是指最不精確的位置，只適合用來理解加減法；乘除法必須直接比較有效位數的數量。

三、科學記號

把數字改寫成科學記號時，數值不能改變，而且原本的有效位數也要完整保留。

標準形式：a × 10n，其中 1 ≤ |a| < 10。
  • 小數點移動幾格，就決定指數的大小。
  • 係數 a 保留幾位數，就代表幾位有效數字。
原數字科學記號有效位數說明
300.3.00 × 1023小數點表示兩個末尾 0 都有效。
30003 × 1031沒有小數點，末尾 0 只用來定位。
16.18701.61870 × 1016最後的 0 是有效數字，不能刪除。
0.003003.00 × 10−33開頭的 0 無效，3 後面的兩個 0 有效。
兩件事要分開：小數點移動格數決定 10 的指數；係數中保留的數字決定有效位數。

CHAPTER 02

一、先用這個流程判斷

  1. 化學式是否以 H 開頭，而且題目把它當酸？
    是 → 使用酸的命名規則；否 → 繼續判斷。
  2. 是否為 metal + nonmetal？
    是 → ionic compound；固定電荷用 Type I，多種電荷用 Type II。
  3. 是否為 nonmetal + nonmetal？
    是 → binary covalent compound，使用數量前綴。
  4. 是否含有 polyatomic ion？
    把多原子離子視為完整的一組，保留它的名稱，不拆開命名。

八、考試最容易錯的地方

  • binary 是兩種元素
    N2O5 仍是 binary compound。
  • 離子化合物不用數量前綴
    MgBr2 是 magnesium bromide。
  • 羅馬數字是電荷
    TiO2 是 titanium(IV) oxide。
  • 固定電荷不寫羅馬數字
    CaO 是 calcium oxide。
  • 共價化合物才使用數量前綴

  • 第一個元素省略 mono-
    CO 是 carbon monoxide。
  • 多原子離子不能拆開
    NaOH 是 sodium hydroxide。
  • 含氧酸不能加 hydro-
    HNO3 是 nitric acid。

  • 能判斷 ionic compound 與 covalent compound。
  • 知道 Type I 與 Type II 的差別。

CHAPTER 05

一、壓力單位

壓力是單位面積所受的力；SI 單位為 pascal（Pa）。

1 Pa = 1 N/m2
1 atm = 101,325 Pa
常用換算：1 atm = 101,325 Pa = 760 mmHg = 760 torr

二、氣體定律

使用氣體定律前，先確認哪些變數保持不變；溫度一律換成 kelvin（K）。

定律固定條件關係常用比較式
Boyle's law
波以耳定律		T、n 固定PV = kP1V1 = P2V2
Charles's law
查理定律		P、n 固定V = kTV1/T1 = V2/T2
Avogadro's law
亞佛加厥定律		T、P 固定V = knV1/n1 = V2/n2

三、分子速率與逸散

方均根速率（root-mean-square speed）

urms = √3RTM
  • R = 8.314 J·mol−1·K−1 時，M 必須用 kg/mol。
  • 所得速率單位為 m/s；同溫下，摩爾質量越小，方均根速率越大。

Graham 逸散定律

vg1vg2 = √M2M1

vg 表示氣體的逸散速率；速率與摩爾質量的平方根成反比，所以較輕的氣體逸散較快。

名詞：diffusion（擴散）是不同氣體彼此混合；effusion（逸散）是氣體通過小孔進入低壓或真空空間。上式是 逸散速率 的比較式。

四、真實氣體方程式修正

1. 高壓：修正分子本身占有的體積

高壓時分子被擠得很近，分子本身的體積已不可忽略，因此實際容積會比理想預測的大。

V = nRTP + nb

2. 低溫：修正分子間吸引力

低溫時分子動能較小，分子間吸引力的影響變明顯，導致分子較少、弱地撞擊器壁，使觀察到的壓力低於理想值。

P = nRTV − a(nV)2

3. van der Waals 方程式：兩項一起修正

[Pobs + a(nV)2] × [Vobs − nb] = nRT
常數物理意義數值意義
a分子間吸引力的壓力修正分子間吸引力較強數值上升；對大小相近的分子而言，極性分子通常比非極性分子大。
b分子有限體積的容積修正分子本身體積大數值上升。
  • 同族非極性粒子通常原子序越高、電子越多、可極化性越大，分散力越強，因此 a 往往上升。

五、真實氣體與理想氣體的差異

用壓縮因子（compressibility factor）判斷真實氣體偏離理想行為的方向。

Z = PVnRT
條件主導因素Z 的結果要聯想到
理想氣體忽略吸引力與分子體積Z = 1PV = nRT
壓力趨近 0分子相距極遠，作用力與分子體積影響都趨小Z → 1所有真實氣體逐漸接近理想行為
低至中等壓力分子間吸引力通常先占優勢，使測得壓力與 PV 偏低Z < 1attraction dominates
很高壓力有限分子體積與短距離排斥占優勢，使實際體積效應變大Z > 1excluded volume dominates

六、空氣污染

光化學煙霧（photochemical smog）

時間順序：NO → NO2 → O3
  1. 引擎高溫使 N2 與 O2 生成 NO。
  2. NO 在空氣中被氧化成 NO2。
  3. 中午的紫外線使 NO2 → NO + O。
  4. 游離氧原子再與氧氣反應：O + O2 → O3，形成臭氧。

酸雨與燃煤脫硫

S→SO2→SO3+ H2O →H2SO4

煤中的硫燃燒生成 SO2，再氧化成 SO3；SO3 與水形成具腐蝕性的硫酸，是酸雨來源之一。

煙道氣洗滌器（scrubber）可利用石灰石除去 SO2：

CaCO3 → CaO + CO2
CaO + SO2 → CaSO3(s)

CHAPTER 07

一、電子能階

  • 光子的能量是量子化的：原子吸收一個光子時，只有在 hν = ΔE 恰好等於兩能階差時才會發生躍遷；不能只吸收光子的一部分。
  • 粒子碰撞：入射粒子的動能只要大於或等於能階差，就能把部分動能轉給電子；剩餘能量仍可成為粒子的動能。
  • 電子往較高能階躍遷會吸收能量；降到較低能階會放出光子，且 Ephoton = |ΔE| = hν = hc/λ。

氫原子的能階差

ΔE = −2.178 × 10−18 J ( 1nfinal2 − 1ninitial2 )
ΔE > 0：吸收光子、躍遷到高能階；ΔE < 0：放出光子、降到低能階。

二、量子力學、軌域與電子組態

Heisenberg 測不準原理

Δx · Δ(mv) ≥ h4π

位置的不確定度 Δx 與動量的不確定度 Δ(mv) 無法同時任意縮小，因此不能把電子描述成具有確定路徑的行星式軌道。

波函數與軌域

  • de Broglie：電子同時具有粒子與波的性質；允許的電子狀態必須形成符合邊界條件的駐波。
  • ψ(r,θ,φ) = R(r)Y(θ,φ)：R(r) 描述徑向分布；Y(θ,φ) 決定角向形狀與方向。
  • |ψ|2 表示在某處找到電子的機率密度；orbital（軌域）不是電子的固定運行路線。

四個量子數

量子數允許值決定
n1, 2, 3, …主能階、軌域大小與大致能量
ℓ0 到 n−1副層／形狀；0、1、2、3 對應 s、p、d、f
mℓ−ℓ 到 +ℓ軌域方向；一個副層有 2ℓ+1 個軌域
ms+½、−½電子自旋；正負是兩種自旋狀態的量子標記
s、p、d、f：分別有 1、3、5、7 個軌域，最多容納 2、6、10、14 個電子。

d 與 f 軌域形狀

穿透、屏蔽與填電子規則

  • 同一主能階的穿透能力：s > p > d > f。穿透越強，越常靠近原子核，受到的有效核吸引越強，能量通常越低。
  • Pauli exclusion principle：一個軌域最多 2 個電子，且自旋相反；同一原子中沒有兩電子具有完全相同的四個量子數。
  • Hund's rule：同能量軌域先各自放入一個平行自旋電子，再開始配對。
  • Aufbau principle：電子先填較低能量的軌域；常用順序為 1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p → 5s。

三、游離能（ionization energy, IE）

從氣態原子或離子移走一個電子所需的能量：X(g) → X+(g) + e−。

  1. 同週期由左到右通常上升：同價層電子無法完全屏蔽增加的核電荷，有效核電荷上升，電子束縛更強。
  2. 同族由上到下通常下降：價電子離核更遠且屏蔽增加，較容易移除。
  3. 連續游離能：移完所有價電子後，再移核心電子會出現巨大跳升；可用跳升位置判斷價電子數。

同週期的兩組重要例外

比較結果原因
s 副層全滿 → 第一個 p 電子IIA > IIIAp 電子能量較高、穿透較差，比全滿 s 電子容易移除。
p 副層半滿 → 開始配對VA > VIA半滿 p 較穩定；VIA 的成對電子排斥使其中一個較容易移除。
第一游離能由小到大的週期口訣：1 → 3 → 2 → 4 → 6 → 5 → 7 → 8（表示 A 族次序）。

四、電子親和力（electron affinity, EA）

氣態原子得到電子時的能量變化：X(g) + e− → X−(g)。

  1. 同週期由左到右：通常變得更負，表示得到電子更有利。
  2. 同族由上到下：通常變得較不負（更正），表示得到電子的吸引力減弱。
  3. Cl 比 F 更有利：F 的 2p 軌域很小且擁擠，新電子受到較強排斥；Cl 的電子親和力因此比 F 更負。
看清楚題目的正負號定義：若 EA 指反應能量變化，越有利通常寫成「越負」；若題目把 EA 當作放出能量的大小，則會說數值越大。兩種說法都可能出現。

  • 同族由上到下降低：價層離核更遠、屏蔽增加，吸引鍵結電子的能力減弱。

偶極矩與分子極性

鍵偶極箭頭由部分正電端指向部分負電端，箭尾以十字符號標示正端。分子是否具有淨偶極矩，還要看所有鍵偶極的向量和；對稱分子可能互相抵消。

晶格能

晶格能大小 = k(|Q1Q2|r)

Q1、Q2 是離子電荷，r 是正、負離子中心間距離。電荷乘積越大、離子距離越小，晶格能大小越大。

百分比離子性

% 離子性 = 測量的偶極矩電子完全轉移時的理論偶極矩 × 100%

實際鍵結是連續變化的；即使電負度差很大，也沒有鍵達到完全 100% 離子性。

二、Lewis 電子模型

  • H 遵守 duet rule，周圍最多 2 個電子。
  • C、N、O、F 等第二週期元素不可超過八隅體。
  • 第三週期以後的中心原子才可能形成 expanded octet。
  • Be、B 常形成不足八隅體；常見情況分別為中心原子周圍 4、6 個電子。
  • 分配剩餘電子時，通常先滿足外圍、電負度較大的原子，再處理中心原子。

三、形式電荷（formal charge）

形式電荷 = 自由原子的價電子數 − 分子中分配給該原子的有效電子數
  1. 所有原子的形式電荷總和，必須等於分子或離子的總電荷。
  2. 比較非等價 Lewis 結構時，形式電荷越接近 0 越好。
  3. 若必須出現負形式電荷，應盡量放在電負度較大的原子上。

四、VSEPR

先畫 Lewis 結構，再數中心原子的電子域。單鍵、雙鍵、三鍵都各算 1 個電子域；每一對孤電子也算 1 個。

  • 5 電子域：孤電子優先放在 equatorial position，因為只有兩個 90° 排斥。
  • 6 電子域：六個位置原本等價；若有兩對孤電子，兩者優先互相呈 180°，形成 square planar 的原子排列。
  • 孤電子排斥力大於鍵結電子，通常會把實際鍵角壓得比理想鍵角小。

一、混成軌域與 π 鍵

電子域數混成混成軌域數剩餘未混成 p 軌域幾何
2sp22linear

  • 混成是原生原子軌域混合，產生方向與能量適合鍵結的新軌域；混成前後的軌域總數守恆。
  • σ 鍵沿核間軸頭對頭重疊；π 鍵由兩個平行、未混成的 p 軌域側向重疊。
  • 單鍵 = 1σ；雙鍵 = 1σ + 1π；三鍵 = 1σ + 2π。
  • π 鍵上下兩側的電子雲要求 p 軌域保持平行，因此會限制鍵的自由旋轉。

二、分子軌域模型（MO model）

  • 原子軌域組合成延伸於整個分子的分子軌域；組合前後軌域數守恆。
  • bonding MO 能量較低；antibonding MO 能量較高，使用星號 * 標示。

鍵級（bond order）

鍵級 = 鍵結電子數 − 反鍵結電子數2

鍵級越大，通常鍵越強、鍵長越短；鍵級大於 0 才預測有淨鍵結。

第二週期同核雙原子的 2p 能階順序

分子重要順序原因
B2、C2、N2π2p < σ2ps-p mixing 使 σ2p 能量被推高。
O2、F2、Ne2σ2p < π2p2s、2p 能量差變大，s-p mixing 減弱。

磁性

  • 有一個以上未配對電子：paramagnetic，順磁性，會被磁場吸引。
  • 所有電子都成對：diamagnetic，反磁性。

異核雙原子：HF

F 的電負度較大，2p 原子軌域能量低於 H 的 1s；因此 HF 的鍵結電子機率較偏向 F。一般而言，同週期原子序增加時，有效核電荷上升，價軌域能量下降。

MO 組合條件：兩個原子軌域要有相容的對稱性，且能量越接近，混合越有效。
