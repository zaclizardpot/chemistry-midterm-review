CHAPTER 01

一、有效位數判斷

有效位數（significant figures）表示一個測量值中具有意義的數字；判斷時要分清楚哪些 0 是測量資訊，哪些只是用來標示小數點位置。

算有效位數的數字

  1. 所有非 0 的數字都有效。
  2. 夾在非 0 數字之間的 0 有效。例如 16.07 有 4 位有效數字。
  3. 有小數點時，末尾的 0 有效。例如 13.00 有 4 位有效數字。

不算有效位數的 0

  1. 第一個非 0 數字前面的 0 無效。例如 0.0012 有 2 位有效數字，0.3 有 1 位有效數字。
  2. 沒有小數點時，整數末尾的 0 通常視為無效。例如依本章採用的規則，150 通常表示 2 位有效數字。
數值有效位數判斷原因
16.074夾在非 0 數字之間的 0 有效。
13.004有小數點，結尾的兩個 0 有效。
0.00122前面的 0 只用來定位小數點。
0.31小數點後、第一個非 0 前的 0 無效。
150通常為 2沒有小數點，末尾 0 通常不視為有效。
整數末尾 0 可能有歧義：300 無法清楚表示想保留幾位有效數字。要表達 1、2、3 位有效數字時，最好分別寫成 3 × 102、3.0 × 102、3.00 × 102。

二、有效位數運算

不是所有運算都使用同一種判斷方式：乘除看「有效位數」，加減看「小數位數」。

乘法與除法

答案的有效位數，等於題目中有效位數最少的數值。

例如：

2.5 × 3.42 = 8.55
2.5 只有 2 位有效數字，因此答案寫成 8.6（2 位有效數字）。

加法與減法

答案保留的小數位數，等於題目中小數位數最少的數值。

例如：

12.11 + 0.3 = 12.41
0.3 只精確到小數第 1 位，因此答案寫成 12.4。
運算判斷標準要找最少的什麼？
乘法、除法有效位數最少有效位數
加法、減法小數位置最少小數位數／最不精確位
不要混在一起：「least digit」若是指最不精確的位置，只適合用來理解加減法；乘除法必須直接比較有效位數的數量。

三、科學記號

把數字改寫成科學記號時，數值不能改變，而且原本的有效位數也要完整保留。

標準形式：a × 10n，其中 1 ≤ |a| < 10。
  • 小數點向左移，指數為正。
  • 小數點向右移，指數為負。
  • 小數點移動幾格，就決定指數的大小。
  • 係數 a 保留幾位數，就代表幾位有效數字。
原數字科學記號有效位數說明
300.3.00 × 1023小數點表示兩個末尾 0 都有效。
30003 × 1031沒有小數點，末尾 0 只用來定位。
16.18701.61870 × 1016最後的 0 是有效數字，不能刪除。
0.003003.00 × 10−33開頭的 0 無效，3 後面的兩個 0 有效。
兩件事要分開：小數點移動格數決定 10 的指數；係數中保留的數字決定有效位數。

CHAPTER 02

一、先用這個流程判斷

不要一看到下標就加 di-、tri-。先判斷化合物是哪一類，再套用規則。

  1. 化學式是否以 H 開頭，而且題目把它當酸？
    是 → 使用酸的命名規則；否 → 繼續判斷。
  2. 是否為 metal + nonmetal？
    是 → ionic compound；固定電荷用 Type I，多種電荷用 Type II。
  3. 是否為 nonmetal + nonmetal？
    是 → binary covalent compound，使用數量前綴。
  4. 是否含有 polyatomic ion？
    把多原子離子視為完整的一組，保留它的名稱，不拆開命名。
為什麼會覺得沒學過？投影片第 38 頁只寫「多原子離子必須背」，並請學生參考課本 Table 2.5，卻沒有在投影片完整列出那張表。

三、Type I：固定電荷的二元離子化合物

  1. 先念陽離子，再念陰離子。
  2. 單原子陽離子直接使用元素名稱。
  3. 單原子陰離子改成元素字根 + -ide。
  4. 不使用 mono-、di-、tri-。
  5. 固定電荷金屬不寫羅馬數字。

四、Type II：可能有多種電荷的金屬

  1. 根據陰離子的總負電荷，反推出金屬的正電荷。
  2. 在金屬名稱後用羅馬數字標出電荷。
  3. 羅馬數字代表金屬電荷，不是原子數量。
電荷羅馬數字投影片例子名稱

六、Type III：二元共價化合物

  1. 適用於非金屬 + 非金屬。
  2. 第一個元素使用完整名稱。
  3. 第二個元素改成 -ide 形式。
  4. 使用前綴表示原子數量。
  5. 第一個元素只有一個時，省略 mono-。
  6. 不使用羅馬數字。

八、考試最容易錯的地方

  • binary 是兩種元素
    N2O5 仍是 binary compound。
  • 離子化合物不用數量前綴
    MgBr2 是 magnesium bromide。
  • 羅馬數字是電荷
    TiO2 是 titanium(IV) oxide。
  • 固定電荷不寫羅馬數字
    CaO 是 calcium oxide。
  • 共價化合物才使用數量前綴
    先判斷元素種類再命名。
  • 第一個元素省略 mono-
    CO 是 carbon monoxide。
  • 多原子離子不能拆開
    NaOH 是 sodium hydroxide。
  • 含氧酸不能加 hydro-
    HNO3 是 nitric acid。

九、考前必背清單

  • 能判斷 ionic compound 與 covalent compound。
  • 知道 Type I 與 Type II 的差別。
  • 會從陰離子總電荷反推金屬電荷。
  • 背熟 mono- 到 deca-。
  • 會把單原子陰離子改成 -ide。
  • 背常見多原子離子的名稱與電荷。
  • 背酸的三組轉換：無氧 hydro…ic、-ate → -ic、-ite → -ous。
