一、先用這個流程判斷

不要一看到下標就加 di-、tri-。先判斷化合物是哪一類，再套用規則。

  1. 化學式是否以 H 開頭，而且題目把它當酸？
    是 → 使用酸的命名規則；否 → 繼續判斷。
  2. 是否為 metal + nonmetal？
    是 → ionic compound；固定電荷用 Type I，多種電荷用 Type II。
  3. 是否為 nonmetal + nonmetal？
    是 → binary covalent compound，使用數量前綴。
  4. 是否含有 polyatomic ion？
    把多原子離子視為完整的一組，保留它的名稱，不拆開命名。
為什麼會覺得沒學過？投影片第 38 頁只寫「多原子離子必須背」，並請學生參考課本 Table 2.5，卻沒有在投影片完整列出那張表。

三、Type I：固定電荷的二元離子化合物

  1. 先念陽離子，再念陰離子。
  2. 單原子陽離子直接使用元素名稱。
  3. 單原子陰離子改成元素字根 + -ide。
  4. 不使用 mono-、di-、tri-。
  5. 固定電荷金屬不寫羅馬數字。
化學式正確名稱提醒
KClpotassium chlorideK+ + Cl−
MgBr2magnesium bromide不是 magnesium dibromide。
CaOcalcium oxide不寫 calcium(II) oxide。

四、Type II：可能有多種電荷的金屬

  1. 根據陰離子的總負電荷，反推出金屬的正電荷。
  2. 在金屬名稱後用羅馬數字標出電荷。
  3. 羅馬數字代表金屬電荷，不是原子數量。
電荷羅馬數字投影片例子名稱
+1(I)CuBrcopper(I) bromide
+2(II)FeSiron(II) sulfide
+3(III)FeCl3iron(III) chloride
+4(IV)PbO2lead(IV) oxide
TiO2：兩個 O2− 的總電荷是 −4，所以 Ti 必須是 +4，名稱是 titanium(IV) oxide。投影片第 49 頁特別用 titanium(II) oxide 當錯誤選項。

五、含多原子離子的化合物

多原子離子要視為完整的一組，命名時保留整組名稱；若化學式需要兩組以上，才在化學式中使用括號。

六、Type III：二元共價化合物

  1. 適用於非金屬 + 非金屬。
  2. 第一個元素使用完整名稱。
  3. 第二個元素改成 -ide 形式。
  4. 使用前綴表示原子數量。
  5. 第一個元素只有一個時，省略 mono-。
  6. 不使用羅馬數字。

七、酸的命名

依投影片的判斷方式，酸通常由化學式最前面的 H 辨認。

1. 陰離子不含氧

hydro- + 陰離子字根 + -ic acid
化學式陰離子酸名
HClchloridehydrochloric acid
HCNcyanidehydrocyanic acid
H2Ssulfidehydrosulfuric acid

2. 含氧酸：-ate → -ic acid

不加 hydro-。

化學式陰離子酸名
HNO3nitratenitric acid
H2SO4sulfatesulfuric acid
HC2H3O2acetateacetic acid

3. 含氧酸：-ite → -ous acid

化學式陰離子酸名
HNO2nitritenitrous acid
H2SO3sulfitesulfurous acid
HClO2chloritechlorous acid
無氧：hydro-___-ic acid　｜　-ate：變成 -ic acid　｜　-ite：變成 -ous acid

八、考試最容易錯的地方

  • binary 是兩種元素
    N2O5 仍是 binary compound。
  • 離子化合物不用數量前綴
    MgBr2 是 magnesium bromide。
  • 羅馬數字是電荷
    TiO2 是 titanium(IV) oxide。
  • 固定電荷不寫羅馬數字
    CaO 是 calcium oxide。
  • 共價化合物才使用數量前綴
    先判斷元素種類再命名。
  • 第一個元素省略 mono-
    CO 是 carbon monoxide。
  • 多原子離子不能拆開
    NaOH 是 sodium hydroxide。
  • 含氧酸不能加 hydro-
    HNO3 是 nitric acid。

九、考前必背清單

  • 能判斷 ionic compound 與 covalent compound。
  • 知道 Type I 與 Type II 的差別。
  • 會從陰離子總電荷反推金屬電荷。
  • 背熟 mono- 到 deca-。
  • 會把單原子陰離子改成 -ide。
  • 背常見多原子離子的名稱與電荷。
  • 背酸的三組轉換：無氧 hydro…ic、-ate → -ic、-ite → -ous。
